# Managed Identity Wizard

Managed Identity Wizard is a Power Platform ToolBox tool for configuring Dataverse managed identities for plugin packages and plugin assemblies.

**Version:** {__APP_VERSION__}  
**License:** Apache-2.0

## Solution Filter

Use the Solution command in the inspector actions menu to limit plugin packages and assemblies to a selected solution. The default view covers all solutions.

<Canvas of={FeatureStories.SolutionFilter} />

## Plugin Packages and Assemblies

Refresh packages to browse plugin packages and plugin assemblies separately for the selected solution. Each component can be inspected for signing and managed identity details, or exported for local use.

<Canvas of={FeatureStories.ComponentLists} />

## Local Inspection

Inspect a local `.nupkg` or `.dll` when the component is available during development. Local inspection works without an active Dataverse connection.

<Canvas of={FeatureStories.LocalInspection} />

## Inspection Details

Inspection reports the signer and the managed identity subject identifier calculated from the component signature. Managed identity subject settings supply the tenant, environment, and cloud values used when calculating the identifier. Certificate details include signer metadata and the certificate chain.

For complete workflows, open the [connected](?path=/story/app--connected), [package inspection](?path=/story/app--inspected-package), [assembly inspection](?path=/story/app--inspected-assembly), and [offline inspection](?path=/story/app--disconnected) stories.
